# 🍳 SmartChef AI

SmartChef AI is an AI-powered recipe chatbot that generates recipes for any food requested by the user.

---

# 🚀 Project Overview

I created the complete frontend of this project using:

- HTML
- CSS
- JavaScript

I designed the complete user interface and user experience using Gemini and frontend development tools.

The backend was developed using:

- Python
- Flask

I used ChatGPT and Antigravity to help build, connect, and debug the frontend and backend together.

For AI recipe generation, I integrated the OpenAI API to generate intelligent cooking instructions, ingredients, preparation steps, and recipe details dynamically.

# ⚡ How SmartChef AI Works

1. User opens the SmartChef AI website.

2. User types the name of any recipe in the chatbot search box.

   Example:
   - Pizza
   - Chicken Biryani
   - Paneer Butter Masala

3. After clicking the send button, the chatbot processes the user's message.

4. SmartChef AI understands the recipe request and generates a detailed cooking recipe using AI.

5. The chatbot replies with:
   - Recipe name
   - Description
   - Preparation time
   - Cooking time
   - Ingredients required
   - Step-by-step cooking instructions

6. The response is displayed instantly inside the chatbot interface.

7. Users can continue asking for different recipes and receive AI-generated cooking instructions in real time.

8. SmartChef AI acts like an intelligent cooking assistant that helps users learn and prepare recipes easily.
